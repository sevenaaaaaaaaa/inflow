# Insight Flow（insFlow）

> 面向所有公司的"大增长"情报与策略操作系统：**数据采集 → 洞察生成 → 策略推荐 → 执行落地 → 效果回流** 的完整闭环。

覆盖企业增长全阶段（冷启动 → 增长获客 → 全生命周期运营 → 商业化优化），内置流量诊断、舆情收集、竞品情报、客户旅程、数据成熟度分析、定制化洞察模型与数据洞察 Agent 七大模块，并**优先与本机自研的 OpenFlow（执行操作系统）和 MFlow（内容营销流水线）打通**，让每一条洞察都能变成可执行、可验证的增长动作。

## 核心设计原则

1. **洞察必须可执行**：每个 Insight 对象强制携带 `recommended_actions`，动作直接映射到 OpenFlow 自动化、MFlow 内容任务或通用 Webhook。
2. **数据源永不绑定**：Bing（2025-08 退役）与 Google CSE（2027-01 停服）的教训写进架构——所有上游走 Source 插件接口，随时可替换。
3. **插件 + Skill 双扩展**：数据源/模型/执行通道用插件（manifest.json + entry.py，与 MFlow 插件规范同构）；Agent 能力用 Skill（Markdown + YAML，跨工具可复用）。
4. **文件优先、轻依赖**：SQLite + Markdown/JSON 文件存储，无消息队列、无重中间件，与 OpenFlow/MFlow 的家族哲学一致，个人可自托管。
5. **合规红线**：不爬小红书/微信公众号全量（用官方开放平台或新榜/清博等数据商），遵守 robots.txt 与各 API 再分发条款。
