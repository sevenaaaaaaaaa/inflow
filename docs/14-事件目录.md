# Insight Flow 事件目录

> 本文件由 `insflow events catalog --write` 从 `insflow/core/event_catalog.py` 生成，不要手改。
> schema_version = 1.0

机器可读：`GET /api/v1/events/catalog`；可加 `?direction=inbound|outbound|internal`。

## 入站信封

- 端点：`POST /api/v1/ingest?workspace_id=<ws>`
- 验签：HMAC-SHA256 over raw body，头 `X-IF-Signature` / `X-Inbound-Signature`
- 密钥：`INSFLOW_INGEST_SECRET`（未配置 fail-closed）
- 幂等：`(workspace_id, source, event_id)`，重放返回 `duplicate`
- 公共字段：`schema_version`, `event|type`, `occurred_at`, `source`, `event_id`, `workspace_id`, `payload|data`

## 入站（伙伴 → IF）

### `content.published`

MFlow 发布成功回流：关联洞察动作 → 进入 14 天验证窗口。

- 方向：`inbound` · 通道：POST /api/v1/ingest
- 必填：`event`, `event_id`
- 可选：`item_id`, `loop_id`, `insight_id`, `url`, `title`, `source`
- 鉴权：HMAC-SHA256 (X-IF-Signature)
- 幂等：是

```json
{
  "schema_version": "1.0",
  "event": "content.published",
  "event_id": "pub-20260920-1",
  "source": "mflow",
  "item_id": "42",
  "insight_id": "ins_abc",
  "url": "https://example.com/posts/pricing-watch",
  "occurred_at": "2026-09-20T10:00:00+00:00"
}
```

## 出站（IF → 伙伴）

### `webhook.generic`

通用出站 Webhook。载荷 event=insight.action，可选 HMAC。

- 方向：`outbound` · 通道：HTTP POST target_ref（ActionRouter）
- 必填：`action_type`, `target_ref`
- 可选：`params_json.url`, `params_json.secret`, `params_json.data`
- 鉴权：HMAC-SHA256 (X-IF-Signature)，密钥 INSFLOW_WEBHOOK_SECRET 或 params.secret

```json
{
  "event": "insight.action",
  "workspace_id": "ws_1",
  "insight_id": "ins_abc",
  "action": "webhook.generic",
  "description": "同步到 n8n",
  "data": {
    "severity": "high"
  },
  "ts": "2026-09-20T10:00:00+00:00"
}
```

### `openflow.webhook_insight`

洞察落入 OpenFlow CDP（零插件通道）。

- 方向：`outbound` · 通道：OpenFlow POST /api/webhook.php
- 必填：`action_type`, `target_ref|connector_id`
- 可选：`title`, `summary`, `severity`, `params_json`
- 鉴权：OPENFLOW_WEBHOOK_SECRET

```json
{
  "id": "ins_abc",
  "workspace_id": "ws_1",
  "type": "competitor_pricing",
  "title": "竞品降价",
  "summary": "定价页 -12%",
  "severity": "high",
  "confidence": 0.8
}
```

### `openflow.automation`

模型建议的自动化动作。载荷 event=if.automation_request。

- 方向：`outbound` · 通道：OpenFlow inbound / 插件路由
- 必填：`action_type`
- 可选：`target_ref`, `params_json.automation`, `params_json.connector_id`
- 鉴权：OPENFLOW_WEBHOOK_SECRET 或 OPENFLOW_PLUGIN_TOKEN

```json
{
  "event": "if.automation_request",
  "visitor_id": "ws_1",
  "automation": "nurture-lead",
  "insight_id": "ins_abc",
  "params": {},
  "source_system": "insight-flow"
}
```

### `openflow.plugin_api`

官方插件专用通道。

- 方向：`outbound` · 通道：OpenFlow /api/plugin/insight-flow/<route>
- 必填：`action_type`
- 可选：`target_ref`, `params_json.route`
- 鉴权：X-Insight-Flow-Signature + 可选 Bearer

```json
{
  "route": "generic",
  "workspace_id": "ws_1",
  "insight_id": "ins_abc"
}
```

### `mflow.create_content`

一键产稿。IF 绝不代用户发布；发布结果走 content.published 回流。

- 方向：`outbound` · 通道：MFlow POST /api/loop/create
- 必填：`action_type`
- 可选：`params_json.template_id`, `params_json.fetch_draft`
- 鉴权：MFlow 控制台 session（保险库存密码）

```json
{
  "action_type": "mflow.create_content",
  "insight_id": "ins_abc"
}
```

### `mflow.register_topic`

把洞察登记进 MFlow 选题状态机，不产稿。

- 方向：`outbound` · 通道：MFlow /api/item/upsert + advance
- 必填：`action_type`
- 可选：`params_json`
- 鉴权：MFlow 控制台 session

```json
{
  "action_type": "mflow.register_topic",
  "insight_id": "ins_abc"
}
```

### `feishu.notify`

飞书告警/日报出站。

- 方向：`outbound` · 通道：飞书自定义机器人 webhook
- 必填：`action_type`, `target_ref|params_json.url`
- 可选：`params_json.secret`, `title`, `summary`
- 鉴权：可选机器人签名 secret

```json
{
  "action_type": "feishu.notify",
  "target_ref": "https://open.feishu.cn/open-apis/bot/v2/hook/xxx"
}
```

### `slack.notify`

Slack 出站通知。

- 方向：`outbound` · 通道：Slack incoming webhook
- 必填：`action_type`, `target_ref|params_json.url`
- 可选：`title`, `summary`
- 鉴权：Webhook URL 即凭据

```json
{
  "action_type": "slack.notify",
  "target_ref": "https://hooks.slack.com/services/T/B/X"
}
```

### `email.send`

邮件通知（stdlib smtplib）。

- 方向：`outbound` · 通道：SMTP
- 必填：`action_type`
- 可选：`params_json.to`, `SMTP_HOST`
- 鉴权：SMTP_USER / SMTP_PASSWORD

```json
{
  "action_type": "email.send",
  "params_json": {
    "to": "ops@example.com"
  }
}
```

## 内部（EventBus / 集成状态页）

### `ingest.rejected`

入站验签失败。

- 方向：`internal` · 通道：EventBus
- 必填：`reason`
- 可选：—

```json
{
  "reason": "signature_mismatch"
}
```

### `ingest.duplicate`

同一 (source, event_id) 重放，已短路。

- 方向：`internal` · 通道：EventBus
- 必填：`event`, `event_id`
- 可选：—

```json
{
  "event": "cdp.order",
  "event_id": "ord-501"
}
```

### `ingest.unmatched`

content.published 找不到关联动作。

- 方向：`internal` · 通道：EventBus
- 必填：`event`
- 可选：`item_id`

```json
{
  "event": "content.published",
  "item_id": "42"
}
```

### `action.proposed`

Agent/MCP 起草待审批动作（未派发）。

- 方向：`internal` · 通道：EventBus
- 必填：`action_id`
- 可选：`insight_id`, `proposed_by`

```json
{
  "action_id": "act_1",
  "proposed_by": "agent"
}
```

### `action.dispatched`

动作已派发到适配器。

- 方向：`internal` · 通道：EventBus
- 必填：`action_type`
- 可选：`insight_id`, `action_id`

```json
{
  "action_type": "webhook.generic",
  "insight_id": "ins_abc"
}
```

### `action.dead`

重试耗尽，进入死信（可人工重放）。

- 方向：`internal` · 通道：EventBus
- 必填：`action_id`
- 可选：`retries`

```json
{
  "action_id": "act_1",
  "retries": 3
}
```

### `feedback.received`

14 天验证窗口产出结论。

- 方向：`internal` · 通道：EventBus
- 必填：`action_id`
- 可选：`effective`

```json
{
  "action_id": "act_1",
  "effective": true
}
```

### `insight.created`

质量门通过后洞察出闸。

- 方向：`internal` · 通道：EventBus
- 必填：`insight_id`
- 可选：`type`

```json
{
  "insight_id": "ins_abc",
  "type": "competitor_pricing"
}
```

### `quota.exceeded`

配额熔断（采集/Agent 停写）。

- 方向：`internal` · 通道：EventBus
- 必填：`source`
- 可选：`limit`

```json
{
  "source": "serper",
  "limit": 20000
}
```

### `source.token_refresh_failed`

OAuth 轮换失败，需重新授权。

- 方向：`internal` · 通道：EventBus
- 必填：`source`
- 可选：—

```json
{
  "source": "ga4"
}
```
