# Insight Flow 驾驶舱与看板设计规划

> v1.0（2026-09-16）。目标：把"Markdown 报告 + 表格"升级为**可视化驾驶舱**，让超级个体一屏看懂全域数据。
> 承接 docs/09 战略定位（全域监测 · 超级个体）。

---

## 1. 设计原则

| 原则 | 说明 |
|---|---|
| 零构建链 | 不引入 webpack/Vite。图表用**服务端渲染 SVG**（Python 生成，内联 HTML），少量原生 JS 只做交互（tooltip/切换） |
| 自包含可导出 | SVG 内联 → 报告可直接打印成 PDF、可复制、可脱敏白标，不依赖外部 CDN |
| 明暗双主题 | SVG 用 `currentColor` + CSS 变量，跟随控制台主题 |
| 信息层级 | 驾驶舱（Cockpit）→ 看板（Panel）→ 图表（Chart）三级；一屏一主题 |
| 图表即证据 | 每张图表可下钻到明细/证据（洞察 evidence），保持"洞察可执行"家族基因 |
| 数据可溯 | 图表标注数据窗口与来源（GSC/GA4/GDELT…），避免"黑盒数字" |

## 2. 图表语言规范（什么数据用什么图）

| 数据形态 | 推荐图形 | 禁用/避免 |
|---|---|---|
| 单值 + 环比 | **KPI 卡**（大数字 + 环比箭头 + 迷你 sparkline） | 用饼图表示单值 |
| 时序趋势（连续） | **折线/面积图**（多序列对比用折线） | 折线画分类数据 |
| 分类对比（离散） | **横向条形图**（名称长时优于柱状） | 3D 柱 |
| 构成占比（≤5 类） | **堆叠条/百分比条**（优于饼图） | 饼图 >6 类 |
| 情绪/分布 | **堆叠百分比条 + 计数徽标** | 饼图 |
| 漏斗/旅程步 | **漏斗图**（含相邻步转化率标注） | 折线替代 |
| 多维评分（5 维） | **雷达图**（成熟度） | 表格硬看 |
| 两维机会矩阵 | **散点四象限**（搜索量 × 竞争力） | 单列排序 |
| 双维交叉（时段×渠道） | **热力矩阵** | 堆叠柱 |
| 进度/配额 | **进度条 / 环形 Gauge** | 纯数字 |
| 事件与异动 | **时间线（Timeline）** | 表格平铺 |
| 明细与检索 | **表格（排序 + 分页 + 状态徽标）** | 图表代替明细 |
| 关键词/话题热度 | **标签条云（带权重字号）** | 纯词云（不可读） |

## 3. 驾驶舱清单（9 个）

### C1 · 情报总览驾驶舱（Overview）★首页
**回答**：我现在最该关注什么？
| 看板 | 数据 | 呈现 |
|---|---|---|
| 全域健康 KPI | 新增洞察数 / 待处理 / 负面预警数 / 采集成功率 / 验证有效数 | 5 张 KPI 卡（含环比 sparkline） |
| 今日情报流 | 洞察（severity 排序） | 时间线 + 严重度徽标，可点击下钻 |
| 风险雷达 | 各监测主体负向占比 | 横向条形图（阈值线标注） |
| 闭环进度 | 洞察状态分布（new→ack→actioned→verified） | 堆叠百分比条 |
| 监测覆盖 | 5 类监控任务数与最近运行状态 | 状态徽标小卡 + 迷你时间线 |
| 快捷动作 | 触发诊断 / 生成周报 / 新建监测 | 按钮组 |

**筛选**：时间范围（24h/7d/30d/90d/自定义）、监测主体、严重度、渠道

### C2 · 舆情驾驶舱（Sentiment）★已有雏形
**回答**：我的品牌/话题在网上被怎么说？
| 看板 | 数据 | 呈现 |
|---|---|---|
| 舆情 KPI | 总提及 / 负面数 / 平均负向占比 / 负面预警数 | KPI 卡 |
| 情绪趋势 | negative_ratio + avg_score 时序 | 双轴折线（占比左轴 / 分数右轴） |
| 渠道构成 | topic_mentions_{news,search,reddit} | 堆叠面积图 |
| 主体热力 | 各主体负向占比 | 横向条形 + 阈值线（35%） |
| 负面预警 | topic_negative_alert | 卡片列表（负面样本 + 命中词高亮） |
| 高频负向词 | 负面命中词频次 | 标签条云（字号=频次） |
| 提及时间线 | 全部提及（标题+来源） | 时间线（按小时分桶） |

**筛选**：主体（多选）、渠道、情绪标签、时间范围、来源域名、关键词

### C3 · 流量驾驶舱（Traffic）
**回答**：流量/转化为什么波动？
| 看板 | 数据 | 呈现 |
|---|---|---|
| 流量 KPI | 点击/曝光/CTR/平均排名/会话/转化 | KPI 卡（每项 7d 环比） |
| 流量趋势 | gsc_clicks、ga4_sessions | 多序列折线（可切换指标） |
| 渠道分解 | Organic/Paid/Referral/Social/Direct/AI | 堆叠柱（按周） |
| 关键词机会 | 曝光 × 排名，CTR 缺口 | 散点四象限（右上=机会） |
| 着陆页表现 | Top 页点击/转化 | 表格（排序 + 迷你条） |
| 技术健康 | CrUX LCP/INP/CLS/TTFB | Gauge 组（good/needs/poor 三色） |
| 异常标注 | traffic_anomaly / conversion_low | 折线图上标注点 |

**筛选**：时间范围、来源渠道、设备（CrUX）、页面/关键词、竞品对比开关

### C4 · 竞品驾驶舱（Competitor）
**回答**：对手在做什么、我差在哪？
| 看板 | 数据 | 呈现 |

**筛选**：竞品（多选）、监控类型（定价/内容/SEO/广告）、时间范围、关键词

## 4. 筛选器体系

**全局筛选（驾驶舱级，右上角）**
- 时间范围：24h / 7d / 30d / 90d / 自定义
- 工作区/客户：多租户/代理场景切换
- 监测主体：话题/品牌/竞品（多选）
- 渠道：news / search / reddit / gsc / ga4 / crux

**局部筛选（看板级）**
- 严重度（critical→info）、状态（new→verified）、洞察类型前缀
- 来源域名、关键词、分群、旅程阶段（S0–S3）
- 置信度下限

**交互约定**
- 筛选即 URL 参数（可分享、可收藏）
- 图表点击 = 下钻（图表 → 明细表 → 洞察证据）
- 时间范围与所有看板联动（一次改，全屏变）

## 5. 报告可视化升级（MD → 可视 HTML）

| 项 | 现状 | 目标 |
|---|---|---|
| 格式 | Markdown | **自包含 HTML**（内联 SVG，可打印 PDF） |
| 图表 | 无 | 按报告类型嵌入对应看板图表（周报=趋势+Top；深度=全量看板） |
| 导出 | 复制 MD | 打印 PDF / 白标 HTML / 分享链接 |
| 数据溯源 | 文本 | 每个图表标注窗口+来源，可点击回看洞察 |

报告结构模板（深度报告）：
`执行摘要(KPI) → 流量(折线+散点) → 竞品(条形+时间线) → 舆情(堆叠条+词云) → 旅程(漏斗) → 行动(命中率) → 90 天路线`

## 6. 技术实现方案

**新增模块**
```
insflow/viz/                 # 服务端 SVG 图表（零依赖）
├── primitives.py           # 坐标轴/刻度/网格/图例/颜色令牌
├── charts.py               # kpi / line / bar / stacked / funnel / heatmap /
│                           # scatter / radar / gauge / timeline / tagcloud / table
└── theme.py                # 明暗主题色板（与 base.html CSS 变量同源）
insflow/web/cockpit/         # 驾驶舱数据聚合（每舱一个 aggregator）
└── aggregators.py          # 从 metrics/insights/actions/events 聚合出看板数据
```

**数据面**：复用现有表（metrics/insights/actions/feedback/events/subscriptions），
补充聚合 API：`GET /api/v1/cockpit/{name}?workspace_id=&range=&filters=`

**渲染路径**：驾驶舱页面 = 控制台路由（Jinja2）+ SVG 组件（服务端生成），
图表数据同时以 JSON 暴露，便于将来换前端图表库或导出。

**报告**：`ReportRenderer` 把报告 Markdown 的图表占位符（如 `:::chart traffic_trend:::`）
替换为对应看板的 SVG，产出可视 HTML。

## 7.1 能力现状与诚实边界（2026-09-17 复核）

**已具备**：13 类图表 · 9 舱 · 服务端 SVG（零依赖/可打印/白标）· TTL 缓存与降采样 ·
hover 提示与十字准线 · 图表下钻（时间序列 + 关联洞察）· 图/表切换 · 单图 CSV ·
全局筛选（时间/主体/渠道，URL 可分享）· **同期对比虚线**（compare）·
**事件标注钉时间轴**（annotations，洞察/动作/验证三类）· **趋势外推 + 置信带**
（forecast_periods，最小二乘 + 1.96σ，明确非 ML 承诺）· **时间轴框选缩放**
（缩放 + 拖拽平移 + 双击复位）· **区间洞察**（框选后拉取该窗洞察/动作/验证结论）·
**Canvas 大数据量渲染**（点数 > 400 自动切换，前端绘制）· **即席探索**
（指标目录 `/console/explore`，选指标 → 图 + 表 + 一键派发动作）·
**嵌入交付**（HMAC embed token + `/console/embed` 只读视图 + 白标公司名 + CLI `insflow embed token`）·
**全链路 a11y**（图表 role=img/aria-label、数据表 scope/caption、按钮 aria-pressed、
屏幕阅读器 `.sr-only`、`prefers-reduced-motion`）。

**运行时约束（实测，2026-09-17）**：
- 控制台/API 响应统一 `Cache-Control: private, no-store`；但 **Cloudflare 等 CDN 可能
  仍缓存 HTML**（实测 `cf-cache-status: HIT`）。因此：
  - 嵌入片段由内联脚本注入 `?_t=<timestamp>` 缓存绕过（`insflow embed token` 输出即含）；
  - 若发现驾驶舱数据停更，先查 CDN 缓存规则（按 Cookie/Query 不缓存）。
- 宝塔/Apache 层若开启 mod_cache，同样需要按 `Cache-Control` 生效或排除 `/inflow/console`。

**第二批已补齐（2026-09-17，P1/P2 余项全做）**：
- 图表：**图例开关**（点击/键盘）· **首屏动画**（尊重 prefers-reduced-motion）·
  **桑基**（路径流量）· **网格地图**（中国 34 省 / 全球 40 市场，近似地理）· **箱线**
  （中位/IQR/离群）· **异常带**（滚动均值 ± kσ 留一法，避免自掩蔽）· **季节预测**
  （季节指数分解 + 趋势，明确 `seasonal-naive + trend`，非 ML）
- 数据规模：折线/散点/热力 **>阈值自动切 Canvas**（400/800/900 点），前端绘制 + 生长动画
- 交互：**cross-filter 跨图联动**（点条形/格子/箱体 → 维度等值过滤全屏，URL 可分享、可清除）·
  **看板自定义布局**（拖拽排序 + 服务端持久化 + **版本历史可回溯**）· 移动端增强 + **PWA**
