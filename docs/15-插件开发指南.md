# Insight Flow 插件开发指南

> 与 `insflow plugin check` / `insflow plugin new` 同源。先脚手架，再改实现，过检才能被调度器自动执行。

---

## 5 分钟上手

```bash
insflow plugin new source my-blog
insflow plugin check plugins/sources/my-blog
# 改 entry.py 的 collect() → 重启服务（Registry 启动时 load_from_directory）
```

类型：`source` | `model` | `action` | `template`。id 小写字母开头，仅 `a-z0-9-`，2–48 字符，**必须等于目录名**。

| type | 生成位置 | 约定入口 | 运行时 |
|---|---|---|---|
| source | `plugins/sources/<id>` | `create_plugin()` → `SourcePlugin` | 启动热加载，进采集路由 |
| model | `plugins/models/<id>` | `create_model()` 或 `evaluate()` | 过检可安装；引擎接线见后续定制批次 |
| action | `plugins/actions/<id>` | `create_adapter()` 或 `execute()` | 过检后热加载进 ActionRouter，出现在 `/api/v1/actions/types` 与洞察派发列表 |
| template | `plugins/templates/<id>` | `template.json`（行业包结构） | `insflow template apply` |

`--out DIR` 写到其它父目录；`--force` 覆盖；`--name` 显示名。

## manifest.json

必填：`id` `type` `name` `version` `entry`。

```json
{
  "id": "my-blog",
  "type": "source",
  "name": "My Blog Source",
  "version": "0.1.0",
  "entry": "entry.py",
  "permissions": ["network"],
  "config": {
    "api_key": { "desc": "上游 Key", "required": true, "secret": true }
  },
  "provides": {
    "metrics": ["my_blog_items"],
    "engines": ["custom"],
    "latency": "standard",
    "cost_hint": "0"
  }
}
```

- `secret: true` 的配置**不得**带 `default`（校验器直接失败）。
- `permissions` 用数组。`network` 仅 source/出站动作需要。
- `provides.cost_hint` 有值则采集 `cost` 进配额账本。

## 约定函数

**source**（与内置 serper/gdelt 同构）：

```python
def create_plugin() -> SourcePlugin: ...
# SourcePlugin.collect(ctx) -> CollectResult(source, kind, items, cost=...)
```

**model**：

```python
def create_model() -> InsightModel: ...
# InsightModel.evaluate(ctx) -> list[dict]  # Insight 草稿，须带 evidence + actions
```

**action**：

```python
def create_adapter() -> ActionAdapter: ...
# ActionAdapter.execute(action, ctx) -> {ok, ref, detail}
```

**template**：`entry` 指向 JSON，字段对齐 `engine/template_pack.py`（`id/monitors/dsl_rules/skills`）。

## plugin check（六项）

`insflow plugin check <dir>` 与市场安装同源：

1. manifest 必填 + type 枚举  
2. entry 文件存在  
3. 约定函数存在  
4. 目录名 = id（否则 warning）  
5. **无明文密钥**（`sk-` / `AKIA` / `api_key = "..."` 等）  
6. permissions 形态

未过检：**可以** `plugin install`，但 `auto_scheduled=false`，调度器不会跑它。

```bash
insflow plugin install marketplace/sources/my-blog
insflow plugin market
insflow plugin uninstall my-blog
```
