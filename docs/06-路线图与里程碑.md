# Insight Flow 路线图与里程碑

> 版本 v1.0（2026-09-16）。节奏假设 1–2 名全栈 + 1 名增长领域工程，每里程碑含验收标准（DoD）。依赖与风险见 §4。

---

## M0（第 1–2 周）：骨架与首个闭环数据流

**目标**：仓库立起来，最便宜的数据源跑通"采集→洞察→MFlow 消费"全链路。

- [ ] 仓库脚手架：`insflow/` 包结构、SQLite 迁移、FastAPI 控制台骨架、`insflow` CLI
- [ ] **SearchProvider 抽象层 + 首批 3 个适配器**（serper / brave / dataforseo-serp）——ADR-3，最高优先
- [ ] 免费舆情底座 3 个 source 插件：**GDELT、Reddit、知乎数据开放平台**
- [ ] Insight 对象 schema + 质量门（无 evidence/无 actions 不得出闸）+ 洞察流 API
- [ ] 配额账本 + 熔断 + 凭据保险库（AES-GCM，fail-closed）
- [ ] **MFlow source 插件**（`MFlow Dev/plugins/insight-flow/`）+ 过 plugin_check
- [ ] MCP Server 骨架（stdio，`list_insights / get_insight` 两工具）

**DoD**：一条真实舆情洞察（如"Reddit 上竞品 X 被高频抱怨某功能"）出现在 MFlow 信号选题流中；`insflow plugin check` 全绿。

## M1（第 3–6 周）：流量诊断 MVP + OpenFlow 零插件通道

- [ ] 第一方接入向导：GSC + GA4 + CrUX（OAuth 流程、配额感知）
- [ ] 流量诊断台（AARRR 映射 + 异常检测 + Insight 生成）
- [ ] DataForSEO Labs 关键词/竞品模型（成本受控）
- [ ] 成熟度评估问卷 v1（DM-1）+ 阶段判定引擎（DM-4）+ 《成熟度报告》
- [ ] **OpenFlow 零插件通道**：IF 洞察 → `POST /api/webhook.php` 落 CDP（集成方案 §3.2）
- [ ] 网站变更监控 MVP（Firecrawl：定价页 + changelog，语义 diff）
- [ ] 飞书/Slack 告警出站

**DoD**：输入域名 + 3 竞品 → 10 分钟内产出含成熟度评分、阶段判定、Top5 行动建议的诊断报告；OpenFlow CDP 中可见 insight 来源属性。

## M2（第 7–10 周）：执行闭环 + Agent

- [ ] **OpenFlow 官方插件 v1**（钩子出站 + `register_api_route` 洞察回读 + 设置页）
- [ ] **`mflow.create_content` 动作适配器**（loop/create + 轮询 + 取稿）+ MFlow 发布 webhook 回流
- [ ] **动作验证状态机**（基线记录 + 14 天窗口 + 验证报告）——北极星指标的基础设施
- [ ] Insight Agent v1：`ask` 问答（工具调用 + 引用溯源）+ 内置 6 个 Skill
- [ ] 内置模型库 v1（8 个：AARRR、LTV:CAC、竞品动量、关键词机会、留存健康、定价异动、NPS、旅程缺口）
- [ ] MCP Server 完整版（HTTP/SSE + 10 工具）+ OpenFlow `register_mcp_tool`（`insight_flow_query`）

**DoD**：一条竞品定价异动洞察 → 一键生成 MFlow 草稿 → 发布 → 14 天后自动收到《验证报告》；OpenFlow Agent 在 Loop 中成功查询 IF 并经审批门执行派生动作。

## M3（第 11–14 周）：竞品情报完整版 + 旅程 + 双向深度集成

- [ ] 竞品档案 + SEO 竞争情报完整版（关键词缺口、排名追踪、外链新增）
- [ ] 广告素材情报（DataForSEO Ads Transparency）
- [ ] 客户旅程模块（框架 + 覆盖热力图 + 断点清单）
- [ ] **IF 作 MCP 客户端读 OpenFlow**（members/leads/orders → 旅程重建 CJ-3、RFM CJ-5）
- [ ] OpenFlow 插件 `register_schedule` 定时同步 + GrowthBrain 读 IF 信号
- [ ] 周报体系（竞品动向/流量诊断/舆情）自动生成 + 落 MFlow `1-2 Insight/Insight Flow Reports/`

**DoD**：旅程热力图使用真实 OpenFlow CDP 事件数据；三份周报无人值守连续运行 2 周。

## M4（第 15–20 周）：开放生态与定制化

- [ ] 自定义规则模型 DSL（无代码配置，IM-3）+ 模型效果追踪（IM-5）
- [ ] 插件市场机制（本地目录 + 手动安装流程先行，registry 后置）
- [ ] Skill 市场格式定稿（跨 Claude/OpenFlow/MFlow 兼容）
- [ ] 多 Workspace（PL-1）+ RBAC（PL-6）+ 审计完善
- [ ] OpenAPI 3.1 发布 + n8n/Dify 模板（官方工作流示例 3 个）
- [ ] 深度报告生成器（多 Agent 协作，顾问场景交付物）
- [ ] 国内企业档数据商对接探路（新榜/清博商务接触，SM-6）

**DoD**：第三方开发者能在不读内核的情况下写出一个 source + 一个 model 插件并通过校验器自动运行。

## M5（第 21 周起）：商业化

- [ ] 云托管版（多租户、按档位挂 L2/L3 数据源组合）
- [ ] 计费与配额产品化（用量可见、超量告警）
- [ ] 私有化部署包（Docker Compose + systemd + 升级通道）
- [ ] 白标报告（代理公司场景）
- [ ] 知乎/微信生态内容营销社区首发 + OpenFlow 开源社区交叉导流

## 依赖与风险

| 依赖/风险 | 影响 | 对策 |
|---|---|---|
| MFlow 控制台无 API token（密码 session） | AC-2 动作适配器需处理会话过期 | IF 保险库存凭据 + 自动重登；向 MFlow 提 token 需求 |
| 知乎数据开放平台配额（搜索 1,000 次/天） | 舆情覆盖上限 | 免费档明示限额；GDELT/Reddit 分担；企业档叠加数据商 |
| DataForSEO 单一供应商（乌克兰主体，合规评估） | L2 主引擎风险 | Semrush/Ahrefs 适配器保持可用（抽象层已保证），客户可选 |
| OpenFlow/MFlow 版本演进（插件接口变动） | 插件失效 | 插件宿主做契约测试；两仓库各留兼容层并在其 CHANGELOG 订阅变更 |
| 单人调度器瓶颈（APScheduler 单进程） | M4 后任务量增长 | 拆分 worker 进程 + 文件锁；再不行上独立 worker + Redis（有明确切换点才做） |

## 每季例行

- 数据源矩阵复审（供应商定价/退役风险，本行业教训：24 个月退役两大 API）
- 模型效果复盘（哪类洞察命中率最高 → 调权重 → 砍无效模型）
- 插件生态健康度（安装量/失败率）
